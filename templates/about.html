About NBA Stats Website

What is this website?

NBA Stats Website is a comprehensive web application and command-line tool for accessing and exploring NBA player statistics. Our platform provides easy access to detailed player performance metrics, team rosters, and historical data across multiple seasons.

Features

    Player Search: Quickly search for any NBA player and view their detailed statistics
    Team Rosters: Browse complete rosters for all 30 NBA teams with player positions and seasons
    Top Players: View the highest scoring players for any season
    Multi-Season Support: Compare statistics across 2021-2022, 2022-2023, and 2023-2024 seasons
    Autocomplete Search: Smart search suggestions as you type
    Responsive Design: Works seamlessly on desktop and mobile devices
    Accessible Interface: Fully accessible with screen reader support

How to Use

Search for a Player:

Use the search bar at the top to look up any NBA player. The autocomplete feature will suggest player names as you type.

Browse Teams:

Click on the "Teams" link in the navigation to view all 30 NBA teams. Click any team box to see the complete roster with player positions and seasons played.

View Top Players:

Visit the "Top Players" page to see the highest scoring players for each season.

Select a Season:

Use the season dropdown to filter results across different NBA seasons (2021-2022, 2022-2023, 2023-2024).

Data

Our database contains comprehensive NBA statistics including:

    Player names, positions, and team assignments
    Games played, points, assists, and rebounds
    Historical data across multiple seasons
    Team rosters and player movements

Technologies

This website is built with:

    Backend: Python, Flask, PostgreSQL
    Frontend: HTML5, CSS3, JavaScript
    Features: Autocomplete search, responsive design, accessibility support

Accessibility

We're committed to making this website accessible to everyone:

    Screen reader support with semantic HTML
    Keyboard navigation support
    High contrast mode support
    Text resizing support (150-200%)
    Responsive design for all screen sizes
