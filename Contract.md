# Team Contract

## Team Goals
We aim to create an interactive NBA player statistics web app that allows users to view and compare stats from the 2023–2025 NBA seasons. Through this project, we want to:
- Improve our technical skills in HTML, CSS, JavaScript, SQL, Python and full stack development.
- Learn to work as an efficient and collaborative development team.
- Build a polished and useful final product we can potentially showcase in our portfolios.

### Ngelek

### Jeremy

## Capitalizing on Strengths
- Amine will act as the team organizer, managing our task board, calendar, and sprint plans.
- Ngelek will lead our troubleshooting, researching, and documentation tasks.

- Responsibilities will rotate to ensure everyone grows and contributes across all areas.

## Team Expectations

### Meetings
- We will meet twice a week: Saturday and Sunday at 8 PM via Zoom, in the Weitz, or Olin.
- Meetings will be around 1 hour and include planning, checkins, and coding.

### Roles
- **Facilitator**: Rotates weekly
- **Agenda Setter & Timekeeper**: Assigned in advance
- **Note Taker**: Rotates weekly, writes brief meeting summary on Google Docs

### Communication
- **Messages** for daily communication
- **GitHub** for all code and collaboration
- **Google Docs** for shared documents and notes
- Team members will:
  - Check Messages daily
  - Notify in Messages if late/missing a meeting
  - Use respectful communication (e.g., no interrupting, listening actively, giving constructive feedback)

### Technologies
- HTML, CSS, JavaScript (frontend)
- Flask or Node.js (backend)
- SQLite or Supabase (database)
- GitHub (version control)
- Google Docs (planning)

### Decision Making
- Aim for consensus on decisions.
- If consensus isn't possible, majority vote decides.
- For technical decisions, deferring to the teammate with the most context is acceptable.

### Delegation
- Weekly task assignments using Messages
- All members contribute code weekly and complete tasks they commit to
- During checkins, we will redistribute tasks as needed

### Conflict Resolution
- If someone is not contributing:
  1. Private one-on-one checkin
  2. Team conversation
- We value:
  - Consistent communication
  - Meeting commitments
  - Doing things early
